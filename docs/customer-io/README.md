# Customer lifecycle campaigns

[Documentation index](../README.md)

Campaign design and workspace lifecycle data contracts for the Customer.io
integration. Campaign schedules and audience rules require configuration in
Customer.io; these pages do not establish that campaigns are live.

- [Module Activation Campaigns](module-activation-campaigns.md)
- [Trial Lifecycle Campaigns](trial-lifecycle-campaigns.md)
- [Customer.io Workspace Lifecycle Data Contract](workspace-lifecycle-data-contract.md)

The campaign guides distinguish proposed messaging from implemented event delivery.
In particular, module milestone names exist but `module_first_value` is not wired
to a current production action. Billing events belong to the Enterprise billing
implementation, and Community browser analytics is disabled by its configuration.

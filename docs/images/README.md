# README visuals

`helpin-support-workflow.webp` is a fictional product illustration reused from
the Helpin customer-support website. It shows Maya’s export conversation, the
existing EXP-142 task, and the customer record. It is not a captured production
conversation or evidence of release availability.

The existing asset was generated with `gpt-image-2.5-sunburst`. No new image was
generated for this README update. The
[source manifest](../../website/src/app/new/products/customer-support/assets/inbox-orbitdesk-sep20.json)
records its provenance, and the
[original prompt](../../website/src/app/new/products/customer-support/assets/inbox-orbitdesk-sep20-prompt.txt)
records the illustration brief. The README uses a copy of the existing 1920-pixel
WebP asset so documentation does not depend on a website asset path.

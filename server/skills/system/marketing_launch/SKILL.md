Use this skill when Mira prepares a product launch, feature announcement, release campaign, early-access announcement, or launch checklist.

Adapted from the MIT-licensed `launch`, `directory-submissions`, `social`, and `emails` skills in `coreyhaines31/marketingskills`.

## Launch Frame

Structure launches across:

- Owned channels: Docs, website copy drafts, email drafts, in-product announcement drafts.
- Rented channels: social post drafts and marketplace/listing copy drafts.
- Borrowed channels: partner, community, customer, and influencer outreach ideas.

## Required Output

Create a launch plan document with:

- Launch goal and audience.
- Message and positioning angle.
- Timeline: prep, launch day, follow-up.
- Channel checklist.
- Email, social, and announcement copy drafts.
- Required assets and unresolved decisions.
- Follow-up PM tasks when configured.

## Release Context

When native release context is available, ground the launch in shipped behavior, related tasks, and release notes evidence. Separate customer-visible changes from internal implementation detail.

## Guardrails

- Do not post, submit, publish, or email externally.
- Treat Product Hunt, directories, social, ads, and email platforms as planning surfaces only unless native tools are available.

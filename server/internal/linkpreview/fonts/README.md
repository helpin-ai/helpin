# Preview fonts

Embedded for deterministic server rendering without remote font requests. All fonts are redistributed under their accompanying SIL Open Font License.

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl), downloaded 2026-11-10. Families: Inter, Noto Sans Arabic, Noto Sans Devanagari, Noto Sans SC, and Noto Emoji. Noto Sans SC supplies CJK glyph coverage; glyph forms use its Simplified Chinese design. Emoji use the monochrome Noto Emoji font.
